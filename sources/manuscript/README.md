# Manuscript Sources

Esta pasta guarda materiais derivados do próprio manuscrito, separados do ficheiro canónico `projecto-completo.md`.

## Estrutura

- `annexes/`: fontes editáveis de anexos ou material técnico integrado no manuscrito.
- `audits/`: versões auditadas, relatórios de comparação e propostas alternativas de redução/revisão.
- `baselines/`: versões base ou snapshots históricos usados como referência.
- `review/`: leituras críticas, mapeamentos de questões de investigação e notas de revisão.

O ficheiro ativo do manuscrito continua na raiz como `projecto-completo.md`; estes ficheiros são apoio e histórico.
