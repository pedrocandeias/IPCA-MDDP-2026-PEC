# Extraction Schema

Use these fields when extracting data from screened-in papers:

- citation
- year
- study type
- device scope
- upper-limb relevance
- personalization method
- anthropometric input used
- parametric modeling used
- interface or interaction contribution
- role of AI
- role of clinician / technician / designer
- user-facing workflow
- validation approach
- key findings for Chapter 7
- limitations
