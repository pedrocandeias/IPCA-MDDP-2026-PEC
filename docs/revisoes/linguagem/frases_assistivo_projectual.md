## Alternativas para «assistivo/assistiva»

O manuscrito não contém ocorrências de «assistivo», «assistiva», «assistivos» ou «assistivas». Caso estes termos venham a surgir numa revisão posterior, a alternativa deve ser escolhida segundo o referente:

- «tecnologia assistiva» → «tecnologia de apoio»;
- «produto assistivo» → «produto de apoio»;
- «dispositivo assistivo» → «dispositivo de apoio»;
- «solução assistiva» → «solução de apoio»;
- «função assistiva» → «função de apoio» ou uma descrição funcional mais específica.

Estas alternativas seguem o uso corrente em português europeu e evitam transportar automaticamente para o manuscrito o adjectivo «assistivo», mais frequente noutras variantes do português.
