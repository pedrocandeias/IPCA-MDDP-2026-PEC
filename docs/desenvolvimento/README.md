# Documentação de desenvolvimento

Documentação técnica relacionada com a plataforma e com os modelos
paramétricos usados na investigação.

- `modelos/`: notas de integração e protocolos de reconstrução dos modelos;
- `avaliacao_ia/`: relatórios, entradas e metadados das avaliações das
  sugestões antropométricas;
- `dimensionamento/`: medições e documentos externos usados para confrontar
  as regras de escala.

Estes documentos registam decisões e verificações técnicas. Não constituem,
por si só, validação clínica ou funcional dos dispositivos.
