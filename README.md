# Projeto de investigação · Pedro Candeias

[Português](https://pedrocandeias.github.io/IPCA-MDDP-2026-PEC/) · [English](https://pedrocandeias.github.io/IPCA-MDDP-2026-PEC/en.html) · [Manuscrito](https://pedrocandeias.github.io/IPCA-MDDP-2026-PEC/manuscrito.html) · [Tese em PDF](https://pedrocandeias.github.io/IPCA-MDDP-2026-PEC/tese.pdf)

Página inicial bilingue, acesso ao HandFab e ferramentas, e leitura anotada da dissertação. As imagens abrem em lightbox com opção de tamanho original. A lista de siglas e os índices são contínuos, a dedicatória tem secção própria e cada nota de rodapé permite voltar ao texto. O PDF corresponde à versão exportada do ODT que serve de fonte ao manuscrito HTML.

Gerado no espaço de trabalho por `tools/conversao/preparar_html_publicacao.py`, a partir das fontes em `tools/conversao/homepage/` e do HTML anotado do ODT.


Os documentos da defesa encontram-se em `docs/defesa/` na branch `main`. A homepage não inclui ligações para esses materiais.
