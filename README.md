# Projeto de investigação · Pedro Candeias

[Português](https://pedrocandeias.github.io/IPCA-MDDP-2026-PEC/) · [English](https://pedrocandeias.github.io/IPCA-MDDP-2026-PEC/en.html) · [Dissertação](https://pedrocandeias.github.io/IPCA-MDDP-2026-PEC/manuscrito.html) · [Dissertação em PDF](https://pedrocandeias.github.io/IPCA-MDDP-2026-PEC/tese.pdf)

Página inicial bilingue, acesso ao HandFab e ferramentas, e leitura anotada da dissertação. As imagens abrem em lightbox com opção de tamanho original. A lista de siglas e os índices são contínuos, a dedicatória tem secção própria e cada nota de rodapé permite voltar ao texto. O PDF corresponde à versão exportada do ODT que serve de fonte ao manuscrito HTML.

Gerado no espaço de trabalho por `tools/conversao/preparar_html_publicacao.py`, a partir das fontes em `tools/conversao/homepage/` e do HTML anotado do ODT.


Os documentos da defesa encontram-se em `docs/defesa/` na branch `main`. A homepage não inclui ligações para esses materiais.

A investigação, o arquivo e os geradores são mantidos num submódulo privado da branch `main`. Esta branch de publicação contém apenas os ficheiros preparados do site e não depende de acesso privado. A bibliografia continua disponível na [pasta pública](https://github.com/pedrocandeias/IPCA-MDDP-2026-PEC/tree/main/material/bibliografia); o [README principal](https://github.com/pedrocandeias/IPCA-MDDP-2026-PEC/blob/main/README.md) apresenta os documentos e a organização atual.
